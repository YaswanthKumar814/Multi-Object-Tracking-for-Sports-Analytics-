# Published results used for the state-of-the-art comparison

`sportsmot_test_published.csv` holds tracker results on the **SportsMOT test set**
exactly as printed in the papers below. Each row names its source table. The
numbers were checked against the PDFs: the three papers agree wherever they
report the same row.

| Source | What it reports |
|---|---|
| Y. Cui, C. Zeng, X. Zhao, Y. Yang, G. Wu, L. Wang, "SportsMOT: A Large Multi-Object Tracking Dataset in Multiple Sports Scenes", ICCV 2023, arXiv:2304.05170, Table 3 | The benchmark paper: FairMOT, GTR, QDTrack, CenterTrack, TransTrack, ByteTrack, OC-SORT, MixSort |
| H.-W. Huang, C.-Y. Yang, J. Sun, P.-K. Kim, K.-J. Kim, K. Lee, C.-I. Huang, J.-N. Hwang, "Iterative Scale-Up ExpansionIoU and Deep Features Association for Multi-Object Tracking in Sports", arXiv:2306.13074, Table 2 | Deep-EIoU (uses an OSNet re-identification model) and BoT-SORT |
| W. Lv, Y. Huang, N. Zhang, R.-S. Lin, M. Han, D. Zeng, "DiffMOT: A Real-time Diffusion-based Multiple Object Tracker with Non-linear Prediction", arXiv:2403.02075, Table 2 | DiffMOT |

`training_setup` is the papers' own column: the data the methods were trained on,
**train** = SportsMOT training set, **train+val** = training plus validation set.

## Why these numbers are not directly comparable with ours

| | Published results | This project |
|---|---|---|
| Evaluation data | SportsMOT **test** set (the dataset covers basketball, volleyball and football) | 3 football sequences of the SportsMOT **validation** set |
| Detector | Trained on SportsMOT, so it detects only the athletes the benchmark annotates | COCO-pretrained YOLO11n, not trained on SportsMOT: it also detects referees, coaches and staff, which count as false positives |
| Training data seen | SportsMOT train (or train + val) | None from SportsMOT; one validation sequence used to choose tracker thresholds |

The comparison therefore places the project in context; it is not a leaderboard
entry. It is generated by `scripts/make_report_tables.py` (table) and
`scripts/run_experiments.py plots` (`results/plots/14_sota_comparison.png`).
